# Package 6E-3 Preregistratie

Voor implementatie vastgelegde synthetische bronbundel en 76 verwachtingen.
Scope: uitsluitend historische doel-/schemagebonden NIET-FYSIEKE workoutreflectie.
Alle verwachtingen staan in _offline/phase6e3/preregistered-cases.json.

De bronbundel vereist een expliciete toenmalige memberkoppeling tussen doel en
workout. Het bestaande live schema bewaart die doelkoppeling niet aantoonbaar;
geen reconstructie uit een huidig doel. Een live bronadapter wordt niet gebouwd.
Ontbrekende/revisie-afwijkende bronnen: feiten waar aantoonbaar, geen reflectie.
Foute persoon-/sessie-/setbinding: invoer afwijzen zonder broninhoud te tonen.
Gedeeltelijke registratie, onbekende eenheid of oefeningsversie: geen volledig
vergelijkings- of reflectievoorstel. Geen omrekening van lbs/plates naar kg.
RIR 0 blijft een waarde; null blijft ontbreken. RPE 0 is geen RIR.
Bereiken zijn gestructureerde min/max, geen gegokte interpretatie van vrije tekst.

De drie exacte NL/EN/DE-excerpten zijn vooraf vastgelegd. Extra tests volgen voor
invoerimmutabiliteit, duplicaten, latere schema-/doelwijzigingen, bindings,
O5 exacte grens/geen verlenging, bronbehoud en isolatie. Geen medische testlabels.
Bestaande 6E-0/6E-1/6E-2-bronnen blijven read-only. Hun frozen waarschuwing/
contexttoestand wordt hergebruikt; geen classifieruitbreiding of deskundige criteria.
