# Package 6E-2 Preregistratie

Expliciet offline OWNER GO op 2026-09-09; baseline e356a4cb951fc3d614035fa0bf547e669b4d045a.
Deze 122 synthetische verwachtingen zijn vastgelegd VOOR de implementatie.
Frozen 6E-1 flow-events leveren context en berichtbinding; fixtures leveren geen
beslissende contextlabels aan de engine. D1-D12 en O1-O5 blijven behouden.

## Vooraf Gekozen Productvoorstellen

- Dagelijkse registratiecontrole: concrete optionele datacontrole op eigen totalen,
  inclusief ontbrekende slaap, zonder ontbrekende waarden te verzinnen.
- Workoutreflectie: zelf een geregistreerde set terugkijken en een aandachtspunt
  noteren, geen geschikte belasting/techniek of volgende oefening afleiden.
- Weekevaluatie: vergelijkbare eigen vensters gebruiken voor een concreet
  terugblik-/planningsaandachtspunt, geen nieuwe trainingsomvang voorschrijven.
- Belasting, voeding, herstel/terugkeer en doelen aanpassen blijven expliciet
  onbeoordeelde inhoudscategorieen. Het toegestane aggregatecontract bevat geen
  gevalideerde doelen, trainergrenzen, techniek of belastbaarheid. Geen nieuwe
  verzonnen autoriteitsvelden toevoegen. Latere coachingambitie blijft behouden.

Registratiecontrole kan naast klachtfeedback blijven bestaan. Workout-/weekreflectie
wordt bij actuele klachten niet aangeboden. Zelfrapportage laat alleen niet-fysieke
reflectie terugkomen onder haar eigen bronvoorwaarden, geen medische vrijgave.
Dit is een nieuw productvoorstel, geen zelfbedachte deskundige hervattingsnorm.
Misverstanden/uitval bieden verduidelijken/retry EN verder chatten. Een nieuwe
duidelijke context kan beperkte reflectie dragen zonder andere meldingen te wissen;
actuele gezondheidsmeldingen blijven voorrang houden. Na O5-verloop/ontbrekende bron
geen reconstructie of vrijgave door tijd, wel zo nodig actuele context vragen.
Geen eeuwige algemene accountblokkade, aanvraagdienst of automatische actie.

## Vooraf Vastgelegde Dekking

Exacte normale NL/EN/DE-antwoorden, nul versus ontbrekend, partial coverage,
bronbundels, verschillende/niet-aansluitende vergelijkingsvensters, toekomstige
vensters, actueel/historisch/ontkend/geciteerd, verduidelijking/retry/zelfrapportage/
herhaling, termijn/vroeger verval/nieuwe bron. Daarnaast contractcontroles voor
rechten, consent, vervalste/verouderde binding, bevroren bronnen en isolatie.
Latere aanvullende randgevallen worden apart benoemd. Oorspronkelijke
verwachtingen worden niet stilzwijgend aangepast om implementatie groen te maken.
Technisch bewijs is geen medische, privacy-, juridische of taalvalidatie.
