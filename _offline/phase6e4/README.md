# 6E-4 Offline Trainer-Bounded Workout Candidates

Node-only, synthetic-only. No provider, live source authority, storage, actions or
runtime entry. T1-T4 are an owner-approved development direction, NOT acceptance
of these implementation results. This package is not frozen.

From repository root:
- node _offline/phase6e4/test/verify.cjs
- node _offline/phase6e4/test/examples.cjs

prepare accepts only issued frozen 6E-1 synthetic flow states and an injected
clock. suggest requires its opaque context plus exact message and readset
bindings and the unchanged existing authority object. Failed/missing authority,
source or safety conditions never give a candidate.

The output mode is candidate_only, with automatic_actions_allowed=false and
physical_advice_authorized=false. All goal/plan/limit values are declared synthetic
source values. Validators prove consistency, not authentic live trainer authority.
One selected option must use one explicit kg or lb unit, matching each set limit.
There is no conversion, rounding, invented progression or retrospective plan change.

assess is a diagnostic adapter, not a complete medical classifier or direct copy
renderer. It preserves original trace/assessment. Full review phrases can explain
unresolved meaning; unconsumed review text remains uncertainty even when an old
generic training-word rule says ordinary. Mixed recognized complaints always win.
The original frozen flow, its issues and O5 projection are never edited or persisted.

No claim that no recognized signal proves fitness. Recovery self-report, expired
records, source loss or a noncurrent statement does not release this new candidate.
Existing frozen chat/facts/nonphysical reflection keep their separate contracts.
The unresolved candidate-resumption boundary is real, not a hidden review service.

Initial preregistration and documented errata are preserved. Known limitations
are not counted as successful recognition. See docs/PHASE6E4_TECHNICAL_REPORT.md
and docs/PHASE6E4_OWNER_OVERVIEW.md for evidence, exact concepts and open reviews.
